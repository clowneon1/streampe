🚀 Streamer Quick Setup Guide

Get your payment alerts live on OBS Studio in 4 simple steps.

01

Download Portable App

Download the portable ZIP archive from GitHub Releases and extract it anywhere on your PC.

02

Launch StreamPe.exe

Run StreamPe.exe. Allow Windows Firewall access on Private networks so local devices can communicate.

03

Connect Companion App

Install the Android companion APK on your phone. Grant Notification Access so it can forward Google Pay & PhonePe alerts.

04

Add Browser Source in OBS

In OBS Studio, add a Browser Source pointing to http://<YOUR-PC-IP>:2907/overlay/alerts (Canvas: 800x600).
