# StreamPe Release Artifact Collector & Organizer Skill

This skill organizes final release binaries for the **PC Desktop App (`pc-server`)** and the **Android Companion App (`android-app`)**, copying and renaming them with proper version tags into the root-level `artifacts/` folder (`d:\xwork\projects\payment-alerts-for-obs\artifacts\`).

## Output Directory & File Naming

All release artifacts are placed in the root-level **`artifacts/`** folder:
```text
artifacts/
├── StreamPe-v2.0.0-Portable.zip    <-- PC Portable Release Archive
└── StreamPe-v2.0.0.apk             <-- Android Release APK (Renamed with version)
```

*(Note: `artifacts/` is listed in root `.gitignore` to prevent tracking binary release files).*

---

## Artifact Collection Workflow

### 0. Clean Old Artifacts
* Ensure root `artifacts/` folder exists (`mkdir -p artifacts`).
* Clean up / delete any existing previous release binaries inside `artifacts/` (`artifacts/*.zip` and `artifacts/*.apk`) before copying new build binaries.

### 1. PC Desktop Portable Archive (`StreamPe-vX.Y.Z-Portable.zip`)
* **Source Location**: `pc-server/dist/StreamPe-vX.Y.Z-Portable.zip` (or root `dist/StreamPe-vX.Y.Z-Portable.zip` generated by `npm run app:dist`).
* **Version Tag**: Read from `pc-server/package.json` (`version`).
* **Action**:
  1. Clean old `.zip` files in `artifacts/`.
  2. Copy `StreamPe-vX.Y.Z-Portable.zip` into `artifacts/StreamPe-vX.Y.Z-Portable.zip`.

---

### 2. Android Companion App APK (`StreamPe-vX.Y.Z-Companion.apk`)
* **Developer Build**: Compiled using custom developer key (`gradlew assembleRelease` or Android Studio build).
* **Source Location**: `android-app/app/release/*.apk`
* **Version Tag**: Read `versionName` from `android-app/app/build.gradle` (e.g. `2.0.0`).
* **Action**:
  1. Ensure `artifacts/` directory exists.
  2. Copy and rename the compiled APK to **`artifacts/StreamPe-vX.Y.Z-Companion.apk`** (e.g. `artifacts/StreamPe-v2.0.0-Companion.apk`).

---
